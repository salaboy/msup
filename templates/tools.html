Add photos to a listing

Etsy blocks servers from reading listing pages, so the photos are collected in your own browser instead. One click per artwork.

Set up once

Show your bookmarks bar, then drag this button onto it:

MSup: grab photos

On iPhone: tap the button, copy the address, then create a bookmark and paste it in as the address.

Each time you add an artwork

  1. Open your new listing on Etsy.
  2. Click through the photos once so they all load.
  3. Click MSup: grab photos. It downloads a file already named after the listing, e.g. 4565863595.json.
  4. Put that file in data/images/ in the repo. On GitHub: open the data/images folder → Add file → Upload files → drag it in from Downloads → commit. No renaming needed.
  5. That's it. Committing the file rebuilds the site and the gallery appears — no sync needed.

If your browser blocks the download, it copies the same text to the clipboard instead and tells you the filename to use.

What's in the file

[
  {
    "url": "https://i.etsystatic.com/…/il_fullxfull.8503570133_1rfk.jpg",
    "w": 3000,
    "h": 2250
  }
]

A plain list of URLs works too, if you'd rather paste them by hand — the width and height are only used to reserve space while the image loads.
